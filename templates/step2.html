API Authentication

Last updated: January 2026

Overview

Our API uses token-based authentication for secure access. All requests must include a valid authentication token in the headers.

Authentication Flow

To authenticate with the API, you need to include the following headers in your requests:

HTTP Headers 
Authorization: Bearer YOUR_API_TOKEN
Content-Type: application/json
X-Api-Version: 2024-01

Endpoint Configuration

The API endpoint for authentication is configured in the system settings. Make sure to use the correct endpoint for your region.

Note: The authentication endpoint requires a specific header format. Please refer to the system configuration for details.

Error Handling

If authentication fails, the API will return a 401 status code. Ensure your token is valid and has not expired.
