Nexus Connector

Browser extension for seamless integration with the Nexus platform. Enables secure communication and authentication.

Version 1.0.0 ~5 KB Chrome 88+
Download Extension View Documentation

Installation Instructions:

  1. Download the extension package
  2. Extract the contents to a local folder
  3. Open Chrome and navigate to chrome://extensions/
  4. Enable "Developer mode" in the top right
  5. Click "Load unpacked" and select the extracted folder
  6. The extension will be installed automatically
